# Simple C# Console Calculator

## Project Description
A robust, interactive command-line calculator built in C#. This application prompts the user for mathematical inputs and performs arithmetic operations while ensuring the application does not crash due to bad input. It was developed as part of the Simulation Academy .NET Diploma Cycle 1.

### Features
*   **Basic Arithmetic:** Supports addition, subtraction, multiplication, and division.
*   **Input Validation:** Handles invalid input reasonably by ensuring users only enter valid numbers and recognized operators (`+`, `-`, `*`, `/`) before proceeding.
*   **Error Handling:** Safely handles division by zero by returning an error message instead of crashing the application.
*   **Continuous Loop:** Allows the user to perform multiple calculations in a row without needing to restart the application.
*   **Clean Output:** Displays the full mathematical equation and the result clearly to the user.
